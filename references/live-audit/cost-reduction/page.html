AI Factory · Experiment 001

Stop paying for repeated AI context.

Heavy Claude Code and Codex users often rebuild expensive context manually. We're exploring a local-first way to reduce unnecessary context re-sends.

The friction we keep seeing

Common themes from heavy agent users — no made-up numbers, just the patterns.

Rebuilding context

Every new session means re-explaining the codebase, the decisions, and the constraints you already covered yesterday.

Repeated context sends

The same files and instructions get re-sent over and over — and every re-send costs tokens.

Unexpected API bills

Usage from redundant re-sends is hard to predict, and the bill doesn't explain itself.

DIY scripts and workarounds

People hand-roll memory files, paste buffers, and scripts to cope. They work — until they don't.

What we're exploring

Three directions we're curious about. None of this exists yet.

  • 01

    Local-first

    We're exploring keeping session context on your machine instead of re-sending it.

  • 02

    Context-aware

    We're exploring smarter, lighter ways to carry project context across sessions.

  • 03

    Transparent cost visibility

    We're exploring clearer visibility into what repeated context is actually costing you.

Who it's for

  • ▸Heavy Claude Code users who run many sessions a day.
  • ▸Codex users who re-paste the same context constantly.
  • ▸Developers juggling dozens of agent sessions across projects.
  • ▸API-budget conscious developers who watch their usage numbers.
