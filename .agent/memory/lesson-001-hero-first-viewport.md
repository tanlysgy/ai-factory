# lesson-001: Hero must fit the first viewport with a single clear CTA

- outcome: success
- source: p5-codeflare
- date: 2026-09-12T08:30:00Z

## what worked

- Hero crammed value, product name, one obvious CTA into the first fold.
- Motion stayed quiet and the interaction demo carried the visual weight.

## what failed

- Earlier drafts with two competing CTAs and long hero copy lost clarity.

## reusable pattern

- Broadcast value immediately; body copy optional on mobile.
- One primary CTA per viewport; secondary actions live below the fold.
