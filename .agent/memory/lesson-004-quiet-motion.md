# lesson-004: Over-animated chunks hurt perceived quality

- outcome: fail
- source: p2-recreation
- date: 2026-09-12T08:45:00Z

## what worked

- A single hero entrance animation set the tone without stealing attention.

## what failed

- Five decorative animations (bouncing cards, spinning badges, scroll-triggered
  fades) made the page feel busy and cheap.

## reusable pattern

- Prefer quiet motion; one intentional interaction beats five decorative ones.
- Animate meaning, not decoration.
