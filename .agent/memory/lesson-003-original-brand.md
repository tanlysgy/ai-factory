# lesson-003: Never copy the reference brand identity

- outcome: success
- source: p3-recreations
- date: 2026-09-12T08:40:00Z

## what worked

- Every published recreation used a fictional brand (Codeflare, Ledger, Relay,
  Lumina) so the demo could be pushed publicly with zero legal ambiguity.

## what failed

- Drafts that leaned on reference logos and taglines had to be replaced.

## reusable pattern

- Always use a fictional brand so the recreation can be published safely.
- Capture the layout and motion, never the identity.
