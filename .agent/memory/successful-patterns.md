# AI Factory — Successful Patterns

What actually worked and should be repeated.

## Raycast recreation (P2)

- Dark launcher-first hero: a realistic app window mock with search input,
  result rows, keyboard hints, and colored icon chips performed strongly.
- Visual evidence captured via full-page + desktop + mobile screenshots and
  computed design signals made recreation deterministic.
- Original "Aurora" brand with geometric CSS shapes proved you do not need the
  reference brand to convey the same product feel.

## Linear recreation — Ledger (P4)

- Light gray/white theme with a single violet-blue accent.
- "Create an issue" input directly appended a card to the inbox column;
  visitors interacted within seconds.
- Effective skeleton: hero → product window → interactive form → feature grid
  (6 cards) → pricing 2-col → CTA → footer.

## Resend recreation — Relay (P4)

- Split demo window: dark request/JSON pane beside live email preview.
- Editing recipient/subject/body updated both the code block and the preview
  instantly — high perceived functionality with zero backend.
- Mono labels ("request", "preview"), 1px borders, and muted neutral palette
  made a plain tool page feel developer-grade.

## Perplexity recreation — Lumina (P4)

- Minimal warm-white landing with a single search input produced the strongest
  "this is a real product" signal for an AI demo.
- Answer panel with source pills made a mock feel trustworthy.

## Common to all winners

- A interactive demo sits directly below the hero.
- Product window tops every page (board / terminal / search).
- Pricing is present even in demo-only sites — it anchors the sale.
- Desktop and mobile screenshots served as the acceptance artifact.
- Quick Tunnel URLs were recorded and the browser opened them before claims.
